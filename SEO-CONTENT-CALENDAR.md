# 90-day SEO content calendar and internal linking map (Moses Mastery)

**Rules for every article:** written from real expertise, no invented client results, statistics or case studies; one primary keyword per article so pages do not compete; each article links to its service page and to Contact, and to 2 related articles.

**About keyword data:** no keyword-tool access was available when this was written, so there are NO search volumes or difficulty scores here. Before writing each article, check the keyword in Google Search Console (queries you already get impressions for), Google autocomplete and "People also ask", and a keyword tool if you have one. Reorder the plan using real data.

### Outline pattern for each article
1. Direct answer in the first 2 to 3 sentences (written so an AI assistant can quote it).
2. The problem and who it affects.
3. Step-by-step fixes with examples a store owner can apply.
4. Common mistakes.
5. When to hire help, with the service-page link and Contact.
6. 3 to 5 FAQs (add FAQPage markup only if the questions are on the page).

## International and German decision
- English pages serve the US, UK, Canada and Australia. Do not duplicate them per country: separate copies compete with each other and add nothing.
- hreflang is only added when a page has a genuine localized twin. Today there is none, so there is no hreflang.
- A German (/de/) section should be written by a native German speaker or reviewed by one, and only if you want to serve German clients (invoices, language, support hours). If yes, start with 3 pages: home, Shopify Agentur / Webdesign, and Shopify SEO Agentur, then add hreflang pairs (en and de-DE) with reciprocal and self-referencing tags.

## What is measured
Use Search Console monthly: queries, impressions, clicks, average position, countries and landing pages. Count Contact form sends, scanner runs (audit_scan), PDF downloads (audit_pdf), chat leads (chat_lead) and WhatsApp clicks from the dashboard. Judge the plan after 90 days, and expect SEO to take longer than that for competitive terms.
