Etsy SEO: How to Write Titles and Tags That Match What Buyers Search

By Moses Daniel, founder of Moses Mastery

  2. Write the title for people first
  3. Use all 13 tags, with variety
  4. Fill in the categories and attributes
  5. Photos and the first image
  6. Description, price and shop details
  7. Common mistakes
  8. When to get help
  9. Common questions

Etsy SEO means making each listing easy for the Etsy search to match with a buyer’s query, and easy for the buyer to click once they see it. In practice that comes down to four things: a clear title built on real search phrases, all 13 tags used with variety, accurate attributes, and a first photo that wins the click. No one can guarantee rankings, but these basics fix the most common reasons good products stay invisible.

1. Start with how buyers actually search

Type your product into the Etsy search bar and note the suggestions that appear. Those are phrases real buyers use. Add what you learn from your Etsy Stats (the search terms that already bring visits) and from the listings that rank for your product. Write down a main phrase for each listing, plus a few close variations. A keyword tool can help, but treat any volume numbers as estimates.

2. Write the title for people first

Etsy allows titles up to 140 characters, but a longer title isn’t better. Put the most descriptive phrase first, because shoppers see the start of the title in search results and on mobile. Describe what the item is, who it is for and one or two key details such as material, style or occasion. Read it aloud. If it sounds like a list of repeated keywords, rewrite it. Stuffing the same words in several times adds nothing and makes the listing look spammy.

Example of the shape: “Personalized Leather Wallet for Men, Engraved Gift for Him, Minimalist Card Holder”. Different phrases a buyer might type appear naturally, and the first words say exactly what the item is.

3. Use all 13 tags, with variety

Each listing has up to 13 tags, and each tag can be up to 20 characters. Use every slot. Choose multi-word phrases a buyer would type, and vary them: don’t repeat the same word in all 13. Mix the product type, the style, the occasion and the recipient. Because tags are short, shorten long phrases to the part that matters. Tags and the title work together, so cover different phrases in each instead of copying one into the other.

4. Fill in the categories and attributes

Choose the most specific category and complete the attribute fields Etsy offers, such as colour, material, occasion and style. These help your listing appear when buyers filter results. Accuracy matters more than filling in everything: only choose attributes that really apply.

5. Photos and the first image

The first photo decides most clicks. Use a clear, well-lit main image where the product is easy to recognise at a small size. Add photos showing scale, detail, packaging and the item in use. Make sure the thumbnail still reads well when cropped.

6. Description, price and shop details

Answer the questions a buyer would ask: size, materials, personalization options, production time and shipping. Start the description with the same plain language you used in the title. Review your shop title, announcement, About section and policies so the shop looks trustworthy, and check your shipping settings, since delivery cost and speed affect how shoppers choose.

Common mistakes

  • Changing every listing at once, so you can’t tell what worked. Start with your best sellers.
  • Copying competitors’ titles word for word.
  • Leaving tag slots empty or repeating the same phrase.
  • Ignoring your own Etsy Stats.
  • Expecting results in days. Give changes some weeks, then compare views, clicks and orders.

Common questions

How many tags should an Etsy listing have?

Etsy allows up to 13 tags per listing. Use all of them with different multi-word phrases a buyer would search for.

How long can an Etsy title be?

Up to 140 characters, but the start matters most. A clear, natural title usually beats a long list of repeated keywords.

How long does Etsy SEO take to work?

Some changes show up in views within days or weeks, but search also depends on sales history, shop activity and competition, so steady improvement takes longer. No one can guarantee results.

Should I rewrite all my listings?

Start with your best sellers and the products with the most potential, measure the change, and then work through the rest.
